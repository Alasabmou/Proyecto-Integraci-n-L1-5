# TrabajoAissDailymotion

uri que devuelve un CANAL: https://api.dailymotion.com/user/shortfilms?fields=id%2Cusername%2Cdescription%2Ccreated_time%2Cvideos_total

uri que devuelve la lista de VIDEOS de un canal y sus TAGS: https://api.dailymotion.com/videos?fields=id%2Ctitle%2Cdescription%2Ccreated_time%2Ctag&channel=shortfilms

uri que devuelve la lista de USERS de un canal: https://api.dailymotion.com/user/shortfilms

uri que devuelve los SUBTITLES de un video: https://api.dailymotion.com/video/xa2wrac/subtitles?fields=id%2Curl%2Clanguage

por qué no aparecen subtitles
